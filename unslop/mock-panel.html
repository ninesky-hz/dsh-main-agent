启用监督循环的模式

勾选后，该模式的下一个新会话会拿到监督者人格和监督工具（start_goal / 派生 worker / 运行中纠偏 / 定时器唤醒），在自己的会话里主动跑循环、往 .agi/ 写状态。有 loader 行的模式立即生效；由插件直接注册的模式写盘后即时重挂载，重挂载不成功时等下次重启。已经在跑的会话保持原样。Main Agent 入口本身就是监督者，无法关闭。

  • Main Agent main-agent
    监督者本身：派生 worker、维护 .agi/ 状态、按定时器唤醒。
    内置入口 · 始终启用
  • General agent general
    通用编码会话，可被委派也可自己派生。
    已启用 · 下一个新会话生效
  • Minimal minimal
    只有读写与 shell，没有监督层。
    未启用
  • Reviewer reviewer
    只读审查模式。
    缺少监督层所需的行，未勾选
