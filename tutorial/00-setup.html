第 I 部分之前 —— 必需的环境准备

从一台干净的 PC 开始

这是本课程唯一受支持的起始状态：没有正在运行的 Harness、 没有 Harness 源码检出、没有 main-agent preset、也没有监督者插件。进入第 1 章之前， 请完成本页的每一项检查。

课程应用如何启动

你能看到本页，说明已经克隆了 dsh-supervisor。就在这份克隆里，那一条本地 安装命令会创建隔离的 Python 环境、只安装评分器所需的 PyYAML 与 zstd 解码器依赖、挑选一个未占用的 localhost 端口，并启动课程服务，且评分按钮可用： 

cd "$HOME/src/dsh-supervisor"
./tutorial/setup.sh

保持那个终端打开，并使用它打印出的 URL。该脚本刻意不 安装 dsh、不克隆 DeepSeek Harness、不配置模型、也不创建你的实验环境；这些学习步骤 仍列在下方。想停止课程服务器时，按 Ctrl-C。

受支持的 shell 与前置条件

这些命令使用 Linux 或 macOS 上的 POSIX shell。在 Windows 上，请在 WSL 里运行。 课程启动器需要 Python 3；在 Debian/Ubuntu 上，它会自动通过 apt-get 补装缺失的 python3-venv 支持。至于 Harness 本身，请安装 Git、Node.js 22 系列的 22.19+ 或 Node 24+， 以及下面的工具。Node 23 不是受支持的 Harness 运行时。请使用 nodejs.org 的 LTS 安装包；在 Ubuntu/WSL 上，其余软件包是： 

sudo apt update
sudo apt install -y git python3

在 macOS 上，用 Homebrew 或你惯用的包管理器安装 Git 与 Python 3。setup 脚本 已经把 Python 评分库安装在仓库内部，因此不会改动你的系统 Python。最后核验 Harness 的前置条件：

git --version
node --version       # v22.19+ in 22.x, or v24+
npm --version
python3 --version
test -x "$HOME/src/dsh-supervisor/tutorial/.venv/bin/python"

安装 DeepSeek Harness

npm install --global @deepseek-ai/dsh
dsh --version

npm 安装出来的才是运行时。下一步的源码检出只用于课程引用的 代码导览；不要修改它。

把 DeepSeek Harness 克隆到课程旁边

课程仓库已经位于 $HOME/src/dsh-supervisor。把 Harness 源码克隆到 它旁边，用于课程引用的代码导览。全局 npm 包仍是运行时；不要修改这份 源码检出。 

mkdir -p "$HOME/src"
git clone https://github.com/deepseek-ai/deepseek-harness.git \
  "$HOME/src/deepseek-harness"

test -f "$HOME/src/dsh-supervisor/package.json"
test -f "$HOME/src/deepseek-harness/docs/architecture.md"
暂时不要安装监督者 bundle

第 6 章会把本仓库安装为一个 profile bundle，这一步发生在任何 dsh-supervisor/… 行被挂载之前。下一次启动时，该 bundle 会安装随包携带的 对应 main-agent preset。把包与 preset 的安装放在一起，可以避免 出现行引用了尚不存在的包名的情况。

启动 dsh 并配置一个模型

在一个终端里启动服务器，并保持该终端打开：

dsh web

打开 http://127.0.0.1:3080，然后进入 Settings → Models，配置一条可用的 provider/model 路由。在模型可用之前， 课程无法测试提示词。终端复用器是可选的；没有任何一章假设你会用它。

创建实验工作区

mkdir -p "$HOME/agi-lab/.agi/subagents"
cp "$HOME/src/dsh-supervisor/agi-template/config.json" \
  "$HOME/agi-lab/.agi/config.json"
touch "$HOME/agi-lab/.agi/NOTES.md" \
      "$HOME/agi-lab/.agi/progress.jsonl" \
      "$HOME/agi-lab/.agi/questions.jsonl" \
      "$HOME/agi-lab/.agi/CHANGELOG.jsonl"
环境闸门 —— 六项全部通过之前不要继续
  1. node --version 在 22.x 系列为 22.19+，或为 24+；下面的课程服务器 setup 检查通过。
  2. dsh --version 执行成功。
  3. 课程仓库与 Harness 仓库都存在于 $HOME/src/ 下。
  4. http://127.0.0.1:3080 能正常打开。
  5. 在标准会话里发一个简单提示词，能收到模型回复。
  6. $HOME/agi-lab/.agi/config.json 存在，且 $HOME/.dsh/profiles/web/package.json 已创建。
